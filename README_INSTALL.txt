راهنمای سریع نصب سایت دوز

1. فایل‌ها را روی هاست آپلود کنید.
2. دیتابیس MySQL بسازید.
3. فایل `database/schema_with_seed.sql` را در phpMyAdmin ایمپورت کنید.
4. اطلاعات دیتابیس را در `config.php` وارد کنید.
5. اگر پروژه داخل پوشه نصب شد، مقدار `APP_BASE_URL` را در `config.php` تنظیم کنید.
6. پنل مدیریت:
   آدرس: /admin/login.php
   کاربر: admin
   رمز پیش‌فرض: siteDooz@1405

نکته‌های این نسخه:
- تصاویر اصلی به WebP فشرده تبدیل شده‌اند.
- اسکریپت‌ها و فونت‌های اضافه حذف شده‌اند.
- لودر اولیه، AOS و Swiper حذف شده‌اند تا صفحه سریع‌تر حس شود.
- هاور کارت‌ها نرم‌تر و سبک‌تر شده‌اند.
- حالت موبایل جمع‌وجورتر و خواناتر شده است.
- دیتای اولیه داخل `schema_with_seed.sql` آماده ایمپورت است.
