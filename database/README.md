# نصب دیتابیس سایت دوز

1. در هاست یک دیتابیس MySQL بسازید.
2. فایل `database/schema_with_seed.sql` را داخل phpMyAdmin ایمپورت کنید. این فایل هم جدول‌ها را می‌سازد و هم دیتای اولیه سایت را داخل دیتابیس می‌ریزد.
3. در فایل `config.php` مقدارهای زیر را با اطلاعات دیتابیس هاست عوض کنید:
   - `DB_NAME`
   - `DB_USER`
   - `DB_PASS`
   - `DB_HOST`
4. بعد از نصب، از پنل مدیریت می‌توانید مقاله، نمونه‌کار، تصویر و بخش نتایج پروژه‌ها را ویرایش کنید.

فایل‌های جداگانه هم موجودند:
- `schema.sql`: فقط ساخت جدول‌ها
- `seed.sql`: فقط دیتای اولیه
